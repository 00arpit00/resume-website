stage 01 · about

The story so far

My path started in 2018 at QA InfoTech, performance-testing 34 enterprise applications with JMeter. The reporting around that work was slow and manual, so I automated it with Jenkins and Python, cutting the effort by 80%. That was my first real taste of what automation can do.

In 2019 I joined Amazon Web Services as a Cloud Support Engineer on the Deployment team. For six and a half years I worked inside customers' hardest problems: Kubernetes capacity, CI/CD pipelines, and Elastic Beanstalk, where I became a subject matter expert and led incident management and root cause analysis.

Since December 2025 I've been a Delivery Consultant in AWS Professional Services, helping Fortune 500 teams modernize. That includes upgrading 74+ Java applications with AWS Transform and Amazon Kiro, and turning what works into published guidance and open-source code that anyone can reuse.
